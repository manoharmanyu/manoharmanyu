## `./featured-projects` — Selected Work

### 01. KRYPT CLI

**Terminal-Based OSINT & Web Security Assessment Framework**

<a href="https://github.com/manoharmanyu/KRYPT-CLI"><img src="https://img.shields.io/badge/VIEW%20SOURCE-0891B2?style=for-the-badge&logo=github&logoColor=white" alt="View KRYPT CLI source code"/></a>
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python"/>
<img src="https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white" alt="Docker"/>
<img src="https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white" alt="SQLite"/>

A terminal-driven security framework that unifies OSINT reconnaissance and defensive web vulnerability assessment in one workflow.

**Key engineering highlights**

- Integrated DNS reconnaissance, Certificate Transparency, subdomain enumeration, and RDAP lookups.
- Developed seven assessment modules covering SQLi, XSS, authentication, authorization, IDOR, exposure, and security headers.
- Designed fail-closed scope enforcement to block scans against unauthorized targets by default.
- Implemented a depth-bounded asynchronous BFS crawler and static JavaScript inspection for API endpoint and route extraction.
- Built a Docker/Python training lab to validate assessment modules against intentionally vulnerable applications.
- Implemented evidence storage with SQLite and report exports in Terminal, JSON, HTML, Markdown, CSV, and PDF formats.
- Included evidence capture and automatic redaction of secrets and tokens.

**Focus:** Responsible security testing, scoped reconnaissance, evidence integrity, and reproducible assessment workflows.

### 02. PESA

**Password Encryption & Security Analysis Suite**

<a href="https://github.com/manoharmanyu/Project---PESA"><img src="https://img.shields.io/badge/VIEW%20SOURCE-0891B2?style=for-the-badge&logo=github&logoColor=white" alt="View PESA source code"/></a>
<img src="https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB" alt="React"/>
<img src="https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white" alt="Node.js"/>
<img src="https://img.shields.io/badge/Web%20Crypto%20API-0F172A?style=flat-square&logo=letsencrypt&logoColor=22D3EE" alt="Web Crypto API"/>

A security-focused application for cryptographic operations, password-security auditing, and security monitoring.

**Key engineering highlights**

- Implemented support for 12 cryptographic algorithms, including SHA-256, SHA-512, MD5, BLAKE2, RIPEMD-160, and AES.
- Designed concurrent password auditing with sub-100 ms processing latency, as reported in the project evaluation.
- Developed an entropy-based vulnerability auditing module that identified a domain-expiry risk with 70% prediction accuracy in the reported test.
- Created a Security Operations Center (SOC) dashboard aggregating threat intelligence feeds.
- Implemented RBAC, TLS 1.3 session security, and exportable vulnerability reports.
- Evaluated the final build through university project inspection and testing by classmates and faculty.

**Focus:** Cryptography, password security, application security, threat intelligence, and security reporting.
